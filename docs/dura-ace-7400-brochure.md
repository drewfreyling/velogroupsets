# Original Dura-Ace 7400 brochure

The [New Dura-Ace brochure, scan 6](https://www.disraeligears.co.uk/site/shimano_new_dura-ace_-_brochure_scan_6.html), dated January 1985 by the archive, gives specifications for the original 7400 equipment. The figures were read from the manufacturer scan and cross-checked against [Shimano SI-N-71](https://si.shimano.com/en/pdfs/si/N-71/SI-N-71-000-00-ENG.pdf). Shimano-hosted service documents remain the primary technical links; the brochure is an additional manufacturer source preserved by Disraeli Gears.

| Component | Brochure information | Catalogue treatment |
| --- | --- | --- |
| RD-7400 | 189 g; 12T minimum / 26T maximum rear sprocket; 26T maximum combined front/rear sprocket difference | Adds the missing 189 g weight and corroborates the existing 26T total capacity and 12–26T sprocket limits. Shimano SI-N-71 independently states the same 189 g and all four limits, including the separate 13T front chainring difference. |
| FD-7400-B / FD-7400-F | 15T maximum front difference; 93 g explicitly for the band type; 28.6 mm clamp | Corroborates the existing 93 g, 28.6 mm band reference and 15T limit. The band weight is not assigned to the braze-on option. |
| FC-7400 / BB-7400 | 637 g for the crankset, 170 mm and 42/52T; bottom-bracket set separately listed at 314 g | Corroborates the existing crank-only 637 g reference with 170 mm arms and 52/42T rings. BB-7400 remains null because the brochure does not identify the weighed spindle length. No combined weight is calculated or apportioned. |
| SL-7400 / FCAIS | 72 g lever figure; SL-7400 uses a 28.6 mm downtube band | Adds the documented mounting configuration and citation. Weight remains null: the figure does not explicitly establish a complete left/right pair. It is not doubled or relabelled as a pair total. |
| HP-7400 | 113 g threaded headset, with thread variants listed | Corroborates the existing 113 g. The weighed thread variant remains unspecified; the existing stack-height reference comes from the later catalogue, not this page. |
| PD-7400 | 372 g per pair, including L-size toe clips | Corroborates the existing pair weight and toe-clip configuration. No claim is added about straps. |

The rear derailleur's **26T combined difference is total capacity**, not a 26T front chainring allowance. Likewise, the front derailleur's 15T figure does not replace the rear derailleur's independent 13T limit or establish that every listed gearing option can be combined.

This review adds one previously unknown canonical weight and supporting citations to seven existing records. It preserves IDs, groupset memberships, existing known weights, manufacturer technical documents and all four rear-derailleur limits. Unknown bottom-bracket and shifter weights follow the [weight guidelines](weights-guidelines.md).
