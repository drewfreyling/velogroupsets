# Shimano MTB clamp-mounted front-derailleur weights

Reviewed on **28 November 2026**. This pass adds **eight weighted components** from Shimano’s 2017–2018 specifications v2.8: the high- and low-clamp versions of four XTR and Deore XT front derailleurs. Each weight identifies the actual **34.9 mm clamp**. Existing records, positive weights, IDs, primary documents and memberships remain unchanged.

## Selecting the weighed clamp

Both specification pages explicitly define the average-weight row as **Band type: L size**. Their mount rows identify **28.6 mm with S-size adapter**, **31.8 mm with M-size adapter**, and the unadapted **34.9 mm** band. The selected reference is therefore the large 34.9 mm clamp without S/M reducer adapters, not an arbitrary choice from available diameters. The L in the weight heading means clamp size; the model’s **-L** suffix separately identifies the low-clamp assembly.

The manufacturer exploded views linked on each record show distinct high-clamp, low-clamp, D-type and E-type assemblies, and separately list the S/M reducer adapters. These records use the complete factory band-mounted assemblies, without claiming an undocumented stripped weight or subtracting hardware. All eight use the manufacturer’s side-swing configuration. The source series rows establish XTR or Deore XT membership; the front/rear speed rows distinguish the double and triple models.

The [earlier direct-mount review](shimano-mtb-derailleur-weights.md) remains separate. No D-type or E-type figure is transferred to a clamp model, and none of these weights is applied to a smaller adapted band. See the [front-derailleur weight guidelines](weights-guidelines.md#front-derailleurs).
