# Shimano 1999 STI Alivio MC18 and cassette review

Reviewed on **23 November 2026** from the [manufacturer-hosted 1999 Shimano STI manual](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/1999_Shimano_STI.pdf). The archive disclaimer identifies the information as updated in 1999. The PDF has **190 pages**; citations distinguish PDF and printed numbers and use PDF page numbers in URL fragments.

This pass adds **one groupset, 14 components and two sourced weights**. Existing component identities, groupset start years, primary technical documents and known masses are unchanged. The catalogue contains four manufacturers, 272 groupsets and 1,973 components after this batch.

## Alivio MC18

The [Alivio overview, PDF page 60 / printed page 59](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/1999_Shimano_STI.pdf#page=60), explicitly says **“Introducing 8-speeds to the Alivio group”** and identifies the MC18 family. The new range uses **1999 documented availability**, without inventing a more precise launch date. It remains separate from the existing seven-speed MC16 and later MC20 references. The [2000 MTB front-derailleur chart](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2000_Shimano_STI.pdf#page=57) also explicitly classifies the Alivio MC18 models in the MTB table.

| Type | Added models / references |
| --- | --- |
| Rear derailleur | RD-MC18, SGS, eight-speed |
| Front derailleurs | FD-MC18 clamp; FD-MC18-E E-set support plate |
| Crankset | FC-MC18, 42/32/22T |
| Controls | ST-MC18 complete combined pair; SL-MC18 complete standalone pair |
| Brakes | BL-MC18 lever pair; BR-MC18 front/rear V-brake pair |
| Rear hubs | FH-MC18; FH-R080 |
| Cassettes | CS-HG50-8I, eight-speed 11–28T and 11–30T references |

The [rear-drive service table, PDF page 105 / printed page 104](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/1999_Shimano_STI.pdf#page=105), explicitly lists **39T total capacity, 30T largest sprocket, 11T smallest sprocket and 20T maximum front difference** for RD-MC18. Its SGS cage and eight-speed configuration are printed, not inferred from the limits. FC-MC18's 42/32/22T configuration is also explicit, but its arm length and mass remain unresolved.

Both rear hubs are listed with **32/36-hole** options. FH-R080 is also explicitly labelled STX-RC in the [2001 hub table, PDF page 84 / printed page 90](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2001_Shimano_STI.pdf#page=84), so it is one shared identity with the existing STX RC range. That row supplies the 135 mm over-locknut reference. Its LX label is not assigned to a particular LX generation without a more precise family reference. Hub weights remain null because the selected sources do not establish skewer exclusion.

## Mounts, brake codes and cassette options

The Alivio overview explicitly identifies the E-set front derailleur's **bottom-bracket plate** and says it needs **no stabilizer boss or frame additions**. This differs from earlier Easy-Set designs that require additional support. The band and E-set models stay separate; the latter is not labelled as a modern direct mount.

The [2000 front-derailleur table, PDF/printed page 56](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2000_Shimano_STI.pdf#page=56), names both FD-MC18 and FD-MC18-E and explicitly supplies **20T capacity, 42T maximum chainring and 10T minimum top/middle difference**. No capacity is calculated from the crank's tooth counts. No actual weighed band or front-derailleur mass is established.

The [Alivio brake service sheet, PDF page 108 / printed page 107](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/1999_Shimano_STI.pdf#page=108), explicitly names **BR-MC18** with ST-MC18 / BL-MC18. The overview's separate **M330** brake reference is not silently rewritten as BR-MC18 or treated as an alias. The exact service-table BR-MC18 assembly is added; its complete front/rear pad-and-bolt-inclusive weight remains unknown. Standalone BL and combined ST controls are separate records.

The overview explicitly describes an **11–30T eight-speed HG50-8I** cassette. The service table names the full **CS-HG50-8I** model and separately gives an **ah 11–28T** reference with 11/12/14/16/18/21/24/28T sprockets. Both directly documented ranges are retained as distinct references; no letter code or tooth sequence is invented for 11–30T. Neither receives an HG50 road-cassette weight, and the `8I` suffix is not dropped or normalised into a different model.

## Qualified cassette weights

The range overview's weight/configuration and the same manual's exact-model service table are cited together. This joins explicit manufacturer facts for the same range and gearing, rather than inventing a cassette code from a derailleur model or treating a family heading as a part number.

The XTR service sheet's **CS-M952** identity is retained even though the overview also names M953 derailleurs. No “CS-M953” cassette is inferred from that adjacent code. Likewise, the LX overview's “Cassette (M570)” heading describes the range; the exact printed model is **CS-HG70-9**, not an invented CS-M570.

These are complete cassette references. Lockring inclusion follows the existing catalogue convention unless explicitly excluded; no separate verification is required. The existing CS-HG70-9 **12–23T** road record and its **236 g** mass remain unchanged. The newly sourced 11–32T assembly has its own ID and does not replace a different configuration's weight.

## Figures not imported

The XT overview gives a **290 g** cassette figure alongside several gearing options without tying the mass to one exact option. It is not assigned to an arbitrary range. The LX rear-derailleur overview's **285 g** figure also does not replace the existing **288 g** selected 2000 reference. Further work can record edition-specific differences without silently overwriting an already qualified reference.
