# Shimano June 1978: EX road ensembles, BMX and Positron

Reviewed on 21 November 2026 from the [original Shimano Bicycle System Components scan](https://vintagecannondale.com/cannondale/shimano/shimano78.pdf). The back cover explicitly says **© June 1978 by Shimano Industrial Co., Ltd.** The file has **16 PDF pages**. Printed product-page numbers are one lower than PDF page numbers: PDF page 8 is printed page 7.

The Dura-Ace EX and Shimano 600 EX groupset records now cite their original road-ensemble spreads. No component identity, weight or limit is imported from this edition. Its early codes need a manufacturer-documented connection to current component records, or exact manufacturer-hosted technical documents for separate identities. Similar appearance, matching weight and family membership alone do not establish an alias. Inventory remains 262 groupsets and 1,604 components.

The product spreads and publication statement were read visually. Text extraction supplies no native text, and OCR misses substantial portions of these scans; no figure below depends on OCR alone.

## BMX and coaster assemblies

PDF pages 12–13 describe motocross bicycles, not mountain-bike membership:

- **HD-400 / HD-410** front hubs: **360 / 400 g**, steel, solid axles with hub nuts, 36 holes. The source prints “Rear” beside their 96 mm over-locknut dimensions despite the front-hub heading; retain that source inconsistency rather than invent a correction.
- **HF-500** motocross hub family: **180 g front / 395 g rear**, 36 holes, 93/110 mm front/rear OLD and a range of rear sprockets. The particular weighed rear sprocket is not selected.
- **CB-400 / CB-410** small-/large-flange coaster assemblies: **833 / 908 g**, 36 holes and several sprocket choices. These are complete hub/brake assemblies, not standalone caliper weights.
- **BB-250 Tourney** rear side-pull caliper: **175 g rear**, **70–88 mm reach**. This early BB code is also a brake, not a bottom bracket.

No BMX range is forced into the current road/MTB/gravel/track categories. No new category or coaster-brake type is introduced in this source review.

## Positron and the control-model gap

PDF pages 14–15 identify:

| Model | Manufacturer listing |
| --- | --- |
| LE-420 Positron 10-s console | **370 g**, top-tube mounting with **1-inch clamp**; one lever controls both front and rear shifting |
| EE-100 Positron front derailleur | **173 g**, lower-inlet **1 1/8-inch clamp**, **14T** capacity; PPS system use |
| DG-300 Positron-400 rear derailleur | **320 g**, front difference **14T**, largest rear sprocket **28T**; PPS system use |
| DG-200 Positron-II rear derailleur | **310 g**, front difference **14T**, largest rear sprocket **28T**; PPS system use |
| LB-700 / LC-410 controls | Down-tube friction / stem friction respectively; no weights supplied |

The “10-speed” console controls a two-chainring/five-sprocket system; it is not a ten-sprocket rear control. It is a single combined front/rear control, not a left/right pair or a genuine single right-hand 1× control. Neither the pair rule nor its 1× exception represents this assembly accurately. A future import would need a separately reviewed control-model extension as well as exact primary documents. No fictional left lever or modern 1× configuration is created.

## Manufacturer-document search and import decision

Public Shimano document queries covered **DA-200, DC-230, EA-200, EC-630, LA-110, LB-630, GA-300, GC-400, GB-110, GB-210, BA-200, MA-200, UA-110, HF-100, BB-330, MB-230, UB-100, HF-300, EE-100, DG-300, DG-200 and LE-420**. No exact early-model technical document was found in the reviewed results. The DA-200 substring result is **PD-A200**, a pedal document, not the EX rear derailleur.

The current RD-7200, RD-6200 and FD-7200 technical-document URLs were also retrieved while checking possible identity bridges; their PDF text layers did not establish an early-code alias. That absence alone is not proof that an alias does not exist. No equivalence is asserted from matching weights or photographs.

The original scan remains useful supporting manufacturer evidence, but its archive host does not satisfy the component primary-document rule. The two road groupsets now cite this edition. Component imports await exact manufacturer documents or documented aliases; missing weight configurations and Positron/BMX modelling questions remain separate issues even if the source-host gap is resolved.
