# Shimano ’72 Bicycle Parts: catalogue and source-gap review

Reviewed on 21 November 2026 from the [owner-supplied original Shimano catalogue](https://drive.google.com/file/d/1zT-QH1v6ODmScB8ZVIetqBqcd49-mPB2/view). The cover explicitly says **’72 Shimano Bicycle Parts**. The file contains **22 PDF pages**, ending with a memo page. Product references below use PDF pages, with printed pages one lower where numbered. Neither file metadata nor later product codes are used to identify this edition.

This is a completed source review, **not a canonical component import**. It identifies early model/weight leads, but exact manufacturer-hosted technical documents were not found for the reviewed pre-prefix models. The catalogue remains unchanged at 262 groupsets and 1,604 components. The original publication is useful supporting evidence; its Drive URL does not satisfy the repository’s current primary-document host rule, and this review does not create an archive exception.

## Controls and hubs

The many **L-number** controls on pages 6–10 include separate five-speed single controls, ten-speed double controls, console/stem controls and internal-hub controls. Examples include **L600** bar-end control for ten-speed, **L120** grip control for Lark-W, and **L110/L150** internal-hub controls. These are not renamed SL-BC10, later Light Action L-series parts or other similarly numbered controls. Single/console mechanisms also need actual control/configuration review; a missing left counterpart or pair weight is not invented.

Page 15 / printed page 14 identifies the front and rear hub assemblies separately:

No masses are supplied on this page. A solid-axle identification is not a weight. No old H code is expanded into an assumed later HB/FH identity.

Page 16 / printed page 15 also lists whole geared-hub figures: **T100 three-speed, 1,100 g; T300 three-speed with coaster brake, 1,350 g; A600 automatic two-speed, 1,400 g**. Exact reference drilling/accessory inclusion is not selected from the listed options. These figures must not become standalone brake weights or unsupported bare-hub references.

## Unnumbered Dura-Ace chainwheel

Page 17 / printed page 16 explicitly uses the **Dura-Ace** name for a forged-alloy cotterless five-arm chainwheel. It lists 39/52T with a protector and 45/54T, 165/170 mm crank lengths, a 68 mm hanger width and an unnumbered axle diagram showing 112 mm overall length. It gives neither a crankset model number nor a weight.

This is useful evidence of the name’s appearance in the 1972 edition. It does not identify FC-7110, BB-7200 or any other later numbered assembly. It also does not establish the formal release date of the complete Dura-Ace range. The existing [Dura-Ace coverage](dura-ace.md) retains its manufacturer-history-based 1973 start; no canonical date or model identity is changed from this unnumbered entry.

## Brakes and early disc reference

Page 18 / printed page 17 identifies:

- **B110** S-type and **B120** M-type centre-pull calipers, without complete pair/position weight references.
- **M110/M120** hooded levers for 22.2/23.8 mm clamps, and **M210/M220** dual-extension levers for those clamp sizes. No pair weights are supplied; M110 is not the later PD-M110 pedal.
- **B700** disc brake, described as two friction pads gripping a **7 inch / 178 mm disc**, using an exclusive 36-hole rear hub. No brake weight, separate rotor model, mounting standard or exact current manufacturer document is established. A hydraulic kit configuration or a standalone rotor identity is not inferred from the photograph.
- **C100** coaster assembly, listed at **860 g**, with a 163 mm axle and several drilling/sprocket options. This is a whole hub/brake assembly figure, not a caliper mass; the specific weighed option is not selected.

The B700 is a valuable early disc-system lead. It is not silently forced into a later hydraulic-system record or given an invented rotor model.

## Primary-document checks and import decision

The repository currently requires each component’s primary technical document to be hosted by its manufacturer, or covered by an explicitly approved exact archive exception. This original Drive scan is supporting manufacturer evidence but has no such primary-host exception.

Checks covered model codes from the rear/front derailleurs, hubs, controls and brakes, including spelling variants such as D500/D-500 and E302/E-302, plus Crane/Titlist/Lark/Thunderbird name searches. No exact model-tag matches were found in the reviewed Shimano public-document results. Targeted searches for manufacturer-hosted 1972 catalogue/Crane/Titlist documents also returned no matching technical document. This records what was found in this review, not a claim that a matching document can never exist.

Some substring results are actively misleading:

- **D501** returns a modern shoe instruction tagged **SH-SD501**, not a 1972 Crane derailleur document.
- D500-like results include **RD-5000/5001**, **FD-5000** and **PD-ED500**, not the old D500 model.
- **M110** can return **PD-M110**, not the caliper brake lever printed here.
- Manufacturer history pages for [Sky Lark](https://www.shimano.com/en/100th/history/products/5.html) and [Tourney](https://www.shimano.com/en/100th/history/products/10.html) establish family background, not exact technical documents or model-specific specifications for all the codes above. Their family dates are not copied to every variant.

No canonical records, weights, groupset dates or source-host rules are changed. The scan is indexed and its concrete findings preserved here. Exact manufacturer-hosted documents, or an explicit primary-source policy change for the original publication, are the remaining prerequisite for a component import. The source’s ambiguous “Capacity” wording, unnumbered crank, configuration options and system-control distinctions still require individual review even if that document-host gap is resolved.
