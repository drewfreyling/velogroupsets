# STX MC34 and 1998 MTB control weights

Reviewed on **22 November 2026** from original Shimano manufacturer dealer manuals. This batch adds **one MTB range, 21 component records and six sourced weights**. Five weights belong to new records; the sixth resolves the existing SL-M739 unknown. Eight existing components gain documented STX MC34 membership without duplicate identities. The catalogue contains four manufacturers, 271 groupsets and 1,898 components after this batch.

## STX MC34 inventory

The [1997 product spread, page 40](https://na.s-tec.shimano.com/s3_assets/filelibrary/Catalogs/1990-2000_TSS_Manuals/1997_Shimano_Dealer_Sales_Support_Manual.pdf#page=40) explicitly names STX as an MTB group and illustrates MC34 components. The [specification table, page 44](https://na.s-tec.shimano.com/s3_assets/filelibrary/Catalogs/1990-2000_TSS_Manuals/1997_Shimano_Dealer_Sales_Support_Manual.pdf#page=44) supplies exact identities and configurations. The new range uses **1997 documented availability**, rather than an unsupported precise introduction date, and remains separate from MC30, MC31, MC32 and STX RC.

| Type | New models |
| --- | --- |
| Rear derailleur | RD-MC34 |
| Front derailleurs | FD-MC34, FD-MC34-E |
| Controls | ST-MC34, SL-MC37 |
| Cranksets | FC-MC34, FC-MC34-B |
| Bottom brackets | BB-LP26, BB-LP26-E |
| Hubs | FH-MC32-S, FH-R050, HB-MC32-S |
| Brakes | BR-MC32-E, BL-MC16 |

RD-MC34's table explicitly lists **7 speeds, 29T total capacity, 30T largest sprocket, 11T smallest sprocket and 20T maximum front difference**. These printed limits are preserved rather than recomputing capacity from the other fields.

FD-MC34 is the clamp model. The E-type footnote explicitly identifies a bottom-bracket support plate and an additional seat-tube boss or clamp adapter; it is not relabelled as a modern direct mount. Both list 20T front capacity, a 42T maximum chainring and a 10T minimum top/middle difference. No actual weighed clamp size or weight is established.

The crank references select the listed 170 mm and 42/32/22T configuration; weights remain unknown. Page 40 says both crank models are available with a chainguard, so the B suffix alone is not treated as proof of a particular fitted guard. BB-LP26 and BB-LP26-E list 110.5/113 mm spindle options without a qualified mass.

Existing FD-MC32, ST-MC35, BB-UN52, BB-UN52-E, CS-IG60, HP-MC30 and HP-MC31 gain membership from the exact STX table. Existing BR-MC32 gains membership from its explicit label on the product spread; the table's BR-MC32-E is recorded separately. BL-MC16 is also pictured and labelled on that STX spread, although its detailed lever specification appears in the adjacent Alivio column. Existing weight references and primary technical documents remain unchanged. In particular, the selected CS-IG60 reference keeps its earlier letter code instead of silently replacing it with a later table's code.

## Complete control-set weights

The [1998 dealer manual, page 32](https://na.s-tec.shimano.com/s3_assets/filelibrary/Catalogs/1990-2000_TSS_Manuals/1998_Shimano_Dealer_Sales_Support_Manual.pdf#page=32) defines a **Rapidfire SL Lever Set**, with both triple front and eight-speed rear controls in each model column. Its assembly weights therefore describe complete left/right sets. Combined ST and standalone SL columns are read separately; no individual-side figure is doubled.

| Model | Complete reference | Weight | Outcome |
| --- | --- | --- | --- |
| ST-M951 | XTR combined 3×8 shift/brake pair | 337 g | Added |
| SL-M740 | Deore XT standalone 3×8 shifter pair | 260 g | Added |
| SL-M739 | Deore XT standalone 3×8 shifter pair | 208 g | Existing null filled |
| SL-M569 | Deore LX standalone 3×8 shifter pair | 249 g | Added |
| SL-MC41 | STX RC standalone 3×8 shifter pair | 289 g | Added |
| BL-M601 | Deore LX V-brake lever pair | 175 g | Added |

The BL-M601 weight row explicitly says **pair**. The standalone SL-M739 figure resolves the blank in the 1997 table without borrowing the already-known 358 g ST-M739 combined-control weight. Cable/housing inclusion is unspecified for these references. These are published assembly totals, not calculated side-weight sums.

The same page identifies BL-MC40 and BR-MC40 in the STX RC column. Both are added with unknown weights. BL-MC40's weight cell is blank; a complete front/rear brake-pair mass including pads and mounting bolts is not established for BR-MC40.

## Remaining source limits

The lower-tier STX inventory tables largely omit weights. Hub figures elsewhere in the 1998 tables do not explicitly exclude skewers and are not imported as qualified hub weights. Cantilever/V-brake assembly units, crank bottom-bracket exclusions, exact weighed front-derailleur bands and bottom-bracket spindle references still require evidence before publishing a mass. Available configurations are not substitutes for weighed configurations.
