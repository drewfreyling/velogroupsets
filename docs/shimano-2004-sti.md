# Shimano 2004 STI service-table review

Reviewed on **22 November 2026** from the [manufacturer-hosted 2004 Shimano STI manual](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2004_Shimano_STI.pdf). This is a **292-page technical information/service manual**, with installation instructions, configuration tables and compatibility notes. It is not the annual trade weight catalogue.

This first pass covers the Saint and selected Deore XT/LX drivetrain tables. It adds **17 component records**, enriches **five existing records**, and adds source citations to four existing ranges. No new groupsets or weights are claimed. The catalogue now contains four manufacturers, 271 groupsets and 1,915 components. Existing IDs, range start years, known weights and primary technical-document URLs are preserved.

The generic FC-M800 record remains intact. The explicitly printed FC-M800-1/-2/-3 codes are added as their own manufacturer-identified configurations, rather than silently changing the existing generic identity into one variant. Selected reference configurations use **170 mm arms**: 34T for the single, 32/22T for the double and 44/32/22T for the triple. Other listed single-ring options are 38, 42 and 46T; no weight is inferred for any option.

The older XT/LX triple references select 170 mm and 44/32/22T. FC-M761 instead explicitly uses **48/36/26T**. Configuration availability does not establish a weighed configuration or mass. These crank records require future weights to exclude the bottom bracket.

The table's named XT/LX series columns establish the older drivetrain identities. Generic suggested pairings elsewhere in the manual do not automatically establish additional groupset memberships: for example, Saint's recommended controls and cassette are not relabelled as Saint-specific components in this batch. No spindle length, hub dimension or weight is filled from a neighbouring model.

## Front-derailleur configurations

The reviewed XT/LX table specifies **22T front difference** and a **12T minimum top/middle difference**. FD-M751 and FD-M571 are clamp assemblies, with listed 28.6/31.8/34.9 mm options; no actual weighed band is specified. FD-M750 and FD-M570 gain their explicit clamp and triple-front information while keeping their existing limits and weights.

The E-type assemblies use a bottom-bracket support plate, as illustrated in the service instructions. They are recorded as such rather than as modern direct-mount derailleurs. No clamp size or mounting weight is guessed for them.

FD-M760's table specifies 44T, 22T capacity and a 12T top/middle minimum. FD-M761 has two conditional references: **48T with a 63–66° chainstay angle**, or **44T with 66–69°**. Its record retains both chainring options and its citation states the condition; it does not imply that both options fit every frame geometry.

## Weight and review limits

The selected service tables do not publish assembly weights. New records therefore use explicit null weights. HB-M800 and FH-M800 still need weights explicitly excluding skewers. Clamp options alone cannot identify a weighed front-derailleur band. No service instruction is treated as a weight source merely because it identifies a model.

Other sections remain useful follow-up material, including Dura-Ace 7800, XTR, Deore, Sora, 2200 and Tourney service tables, brake assembly instructions, and the rear-hub/cassette interchangeability charts. This review does not claim a full page-by-page audit of all 292 pages.
