# Deore XT II and Deore II: the 1989 catalogue

**22 November follow-up:** [CS-MT62 is now included at 325 g](mtb-catalogue-followup-2026-11-22.md) for the documented seven-speed 13–30T configuration. Its missing matching technical link no longer blocks addition; the original review below records the earlier batch.


Reviewed on 21 November 2026 from the [original Shimano catalogue scan supplied by the owner](https://drive.google.com/file/d/1DjMjm22K9deQRXb2jHrivPKqs0Y_FAYr/view). This is the same 36-page scan used in the [Santé review](shimano-sante-1988.md): identified as the 1989 catalogue, with copyright August 1988 and printing code `1088`. All page references below are **PDF pages**.

This batch adds eight component records and thirteen previously unknown weights. Two conflicting existing weights are withheld. The catalogue contains 1,465 component records after this batch. Stable existing IDs, slugs, model numbers and primary technical-document URLs are preserved. Each new record uses an exact Shimano-hosted assembly drawing as its primary document; the original catalogue is supporting evidence for weights and group membership.

The catalogue separates FC-MT60’s 740 g crank weight from the BB-MT60 figure; no bottom-bracket subtraction is used. The existing manufacturer drawing explicitly identifies FC-MT60 as Biopace. Its Deore II membership is added alongside its existing Deore membership. PD-MT60 likewise gains the explicitly listed Deore II membership while retaining its existing Deore DX membership.

Both headset tables list English/Italian BC 1 inch × 24 TPI threads, 30.2 mm cup races, a 26.4 mm crown race and 11.5 mm lower stack. Pedal accessories and shifter cable/housing inclusion are not invented. The brake-lever figures explicitly apply to the two-finger models, not BL-M732 or BL-MT62 four-finger levers.

## Rear-derailleur scope

RD-M732-SGS and RD-MT62-SGS list 38T total capacity, 12T minimum sprocket and a 28–32T maximum-sprocket range **conditional on Shimano SFR/SF fork ends**. The 32T value retains that condition in the records. The maximum front-chainring difference remains unknown; total capacity is not reused as a front-only limit.

The legacy RD-M730 entry on page 25 explicitly labels its existing 265 g reference **SGS**, despite listing GS and SGS models together. Its canonical identity is preserved, with `reference_model: RD-M730-SGS` and `cage: SGS` identifying the weighed configuration. The same reference fields qualify the existing generic RD-M732 and RD-MT62 identities. None of these weights is assigned to another cage version.

## Further leads and limits

- Page 27 gives CS-MT62 as 325 g for seven-speed 13/15/17/20/23/26/30T. It remains a documented lead: an exact manufacturer-hosted CS-MT62 technical document was not found. The FH-MT62 service instruction covers freehub/cassette installation but does not identify the CS-MT62 assembly by model, so it is not substituted as an exact primary document.
- Page 24’s FC-M730 weight is for the earlier high-performance Biopace triple. It is not transferred to the existing later Round Gear SG-X or separate SG reference.
- The SL-M732 figure does not explicitly establish a pair basis; it is not doubled or imported as a pair weight.
- Hub figures say rear without sprockets or give front figures without establishing skewer exclusion. They remain unsuitable for canonical hub weights.
- Page 24’s front-derailleur capacity table names FD-MT62 guide variants, so its capacities are not copied to FD-M732.
