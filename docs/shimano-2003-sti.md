# Shimano 2003 STI technical-table review

Reviewed on **22 November 2026** from the [manufacturer-hosted 2003 Shimano STI manual](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2003_Shimano_STI.pdf). This **137-page PDF** contains technical notes and service instructions, including several landscape service sheets. The contents page is not a reliable direct PDF-page index; citations below distinguish PDF and printed page numbers explicitly.

This first pass adds **18 components** to the existing Deore, Deore XT and XTR ranges, with source citations on those three groupsets. It adds no new ranges or weights and preserves all existing component identities, primary documents and known weights. The catalogue contains four manufacturers, 271 groupsets and 1,933 components after this batch.

## Deore crank variants

The [crank/BB/chainline chart, PDF page 54 / printed page 53](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2003_Shimano_STI.pdf#page=54) explicitly groups these eight models under **Deore**. Suffixes are transcribed as printed, including the letters in **FC-M510-KO**; they are not invented positional variants or assumed aliases.

| Exact model | Printed interface | Chaincase support explicitly marked |
| --- | --- | --- |
| FC-M510-O | Splined | Not marked |
| FC-M510-KO | Splined | Yes |
| FC-M510 | Square | Not marked |
| FC-M510-K | Square | Yes |
| FC-M480 | Square | Not marked |
| FC-M445 | Splined | Not marked |
| FC-M440-O | Splined | Not marked |
| FC-M440 | Square | Not marked |

These are documented catalogue-era associations with the existing Deore M510 range, not claims of exclusive branding or a common introduction date. The table's interface heading says **Spline**, so the records retain that wording rather than inventing a more specific interface standard from a model number.

The [chainring chart, PDF page 52 / printed page 51](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2003_Shimano_STI.pdf#page=52) explicitly gives FC-M480, FC-M445 and FC-M440 **44/32/22T**, and FC-M510 both **44/32/22T and 48/36/26T**. Those base-model configurations are not automatically transferred to separately suffixed models. The selected tables do not establish exact arm lengths or assembly weights. The subsequent [2001 service review](shimano-2001-sti.md) identifies exact FC-M510 and FC-M510-K arm/ring configurations; other suffixes still need their own references. Every new crank weight therefore remains null and any future weight must identify the exact arms/rings and exclude the bottom bracket.

## Front derailleur

PDF page 52 also names **FD-M511** in its Mega-9 triple-front column, with **22T capacity, 12T minimum top/middle difference and 44/46/48T largest-chainring options**. The [manufacturer's discontinued-products index](https://bike.shimano.com/en-AU/products/discontinued.html) explicitly classifies FD-M511 as **DEORE**; group membership is not inferred from the numeric suffix alone. Its clamp/mount configuration and weight remain unresolved by the selected table.

## Early hydraulic disc calipers and levers

The [hydraulic-disc chart, PDF page 56 / printed page 55](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2003_Shimano_STI.pdf#page=56) explicitly names XTR, Deore XT and Deore series columns. It supplies five missing calipers and two standalone lever pairs.

| Model | Range | Selected assembly/mount reference |
| --- | --- | --- |
| BR-M966 | XTR | Front-only post-mount caliper |
| BR-M755 | Deore XT | International Standard caliper; front post-mount adapter support also listed |
| BR-M555 | Deore | International Standard caliper |
| BR-M555-M | Deore | Front-only post-mount model for Manitou forks |
| BR-M525 | Deore | International Standard front/rear reference; front post-mount option also listed |
| BL-M755 | Deore XT | Complete left/right hydraulic brake-lever pair |
| BL-M555 | Deore | Complete left/right hydraulic brake-lever pair |

Front-only models retain that position. Other unknown-weight calipers use the supported unpositioned **Single** reference rather than inventing a front/rear distinction. Piston counts remain null because this chart does not establish them. No complete brake-system mass or lever average is transferred to a caliper, and no pad/bolt-inclusive weight is claimed.

The chart also lists **BR-M755-DH** with mount-specific conditions; that model is left for a more detailed assembly review. Neither compatibility with a named hose nor a suggested rotor implies a fully specified, weighed complete system.

## Rotors

Two new rotor records retain one rotor and its exact diameter:

- **SM-RT96, 160 mm, Center Lock:** PDF page 56 / printed page 55 explicitly calls it a lockring-type mount in the XTR rotor column.
- **SM-RT75, 160 mm, six-bolt:** the same table identifies its model, diameter and XT association. The [installation instructions, PDF page 111 / printed page 110](https://na.s-tec.shimano.com/s3_assets/filelibrary/STI/1993-2012_STI/2003_Shimano_STI.pdf#page=111), explicitly name SM-RT75 and illustrate six numbered rotor-fixing bolts. The mount is not guessed from bolt-circle diameter alone.

Both weights remain null. Installation hardware does not establish whether hardware was included in an unpublished mass. The subsequent [2002 service-table review](shimano-2002-sti.md) resolves SM-RT60’s mount from its own named installation diagram and adds that rotor with its exact 2003 diameter reference. SM-RT75M, SM-RT75-DH and SM-RT60 are not automatically assigned the mount/weight of SM-RT75, nor is SM-RT60 treated as an alias of the SM-RT61 named in another service sheet.

## Further review

The remaining XTR service sheets, 105/2200/A050 drivetrains, Tourney/Altus systems, freehub charts and additional brake variants remain follow-up material. This is a targeted technical-table pass, not a complete page-by-page audit. Hybrid-oriented C-series and Nexave entries are not forced into an unsupported MTB/road category. None of the tables reviewed here publishes a compliant new component weight.
