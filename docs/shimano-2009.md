# Shimano 2009 dealer-manual follow-up

The owner supplied the [2009 Trade Sales Support Manual](https://na.s-tec.shimano.com/s3_assets/filelibrary/Catalogs/1990-2000_TSS_Manuals/2009_Trade_Sales_Support_Manual.pdf). This partial review on **22 November 2026** checked the original scanned specification tables visually, using OCR only to locate entries. The reviewed PDF has 276 pages; the page numbers below match the printed numbers.

This batch adds **21 component records**, including **15 known weights**, fills the existing RD-M662 SGS reference at **258 g**, and fills all four previously unknown limits for the existing RD-M970 SGS reference. There are **16 newly published weights** in total. Existing component IDs, primary technical documents and previously known weights are preserved. New records link directly to the relevant manufacturer-hosted manual page.

## Derailleur variants

[Page 208](https://na.s-tec.shimano.com/s3_assets/filelibrary/Catalogs/1990-2000_TSS_Manuals/2009_Trade_Sales_Support_Manual.pdf#page=208) explicitly distinguishes XTR models and cages; [page 209](https://na.s-tec.shimano.com/s3_assets/filelibrary/Catalogs/1990-2000_TSS_Manuals/2009_Trade_Sales_Support_Manual.pdf#page=209) does the same for Deore XT and SLX. All the following references are nine-speed, with a maximum sprocket of 34T, minimum sprocket of 11T and maximum front difference of 22T.

The parenthesised skewer figures are not part of the canonical hub weight and have not been subtracted from a combined weight. None of these tables identifies a single weighed spoke-hole variant.

## Figures withheld and remaining scope

- The FC-M970/FC-M770/FC-M660 crank tables explicitly include the bottom bracket in their published totals. No subtraction is used to produce a standalone crank weight.
- Several road crank weights on page 218 likewise include the integrated bottom bracket and do not identify one chainring configuration. Existing standalone crank weights remain unknown.
- The Tiagra and Sora derailleur/control weight cells on page 217 are largely blank. Their capacities do not establish weights.
- The SL-M660 shift-lever set figure is a research lead; this batch does not change its pair weight without resolving the reference basis explicitly.
- Road hub figures already held for Dura-Ace, Ultegra and 105 were cross-checked; matching figures do not count as newly filled gaps.
- This is a review of selected product spreads and specification pages 204–221, not an exhaustive audit of all 276 pages.
